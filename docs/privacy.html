RowCraft Extractor — Privacy Policy

Effective Date: October 30, 2026

RowCraft ("Table to CSV & Excel: RowCraft Extractor") is engineered as a privacy-first, client-side Chrome Extension built on Manifest V3.

1. Zero Collection of Webpage or Table Content

RowCraft parses and converts all DOM tables, rows, and cells 100% locally inside your browser's volatile memory (RAM). Your extracted table contents, webpage URLs, and browsing history are never uploaded, transmitted, or shared with any external server.

2. Minimal On-Demand Permissions

  • No Background Host Access: RowCraft never requests <all_urls> or background host permissions.
  • activeTab & scripting: Executed strictly on-demand when you explicitly click the RowCraft toolbar icon to inspect tables on the active tab.
  • storage: Uses local browser storage (chrome.storage.local) solely to store Terms of Service acceptance, local export count, and pricing survey cohort state.

3. Anonymous Pricing Survey Telemetry (500+ Row Tables)

When exporting a table exceeding 500 rows, RowCraft displays an optional 1-click pricing feedback prompt and sends a strictly anonymous event payload ({ event, rowCount, variant, choice, timestamp }) containing zero webpage URLs, zero table content, and zero personal identifiers.
