2. Description of Software & Local Operation

RowCraft is a client-side browser productivity utility that extracts and parses structured HTML tables, CSS grid containers, and ARIA data elements from user-visited web pages into downloadable file formats (such as CSV and Excel) or clipboard text. The Software operates strictly within your local browser environment. The Software does not transmit, store, or process your target webpage content or extracted table data on any external server.

3. Free Edition & Anonymous Pricing Feedback

  • Free Edition: Provided at no monetary cost, permitting table data extraction into CSV, native Excel (.xlsx), and clipboard formats up to 500 rows per table. Features and limits may be modified or phased at the sole discretion of the author.
  • Anonymous Pricing Survey: When exporting tables exceeding 500 rows, the Software may display a 1-click pricing feedback prompt and log a strictly anonymous telemetry event (containing row count, price variant, and user vote—never webpage URLs or table content) before immediately completing the 500-row export.
